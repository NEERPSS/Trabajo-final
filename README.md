# SIMTELE-WEB
Panel educativo de prevención y monitoreo inspirado en Mi Teleférico (simulación, sin datos reales).

**Integrantes:** -Gerzon Fernando Santalla Rivera

**Módulos:** 1) Detención de emergencia, 2) Mantenimiento, 3) Viento y oscilación, 4) Sensores.
**Extras:** reloj en vivo y botón de parada general simulada.

**Uso:** abrir `index.html` o la URL de GitHub Pages, llenar los formularios y pulsar los botones.
Los umbrales son didácticos, no límites operativos reales.
